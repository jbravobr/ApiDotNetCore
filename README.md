# API e aplicação web em ASP.NET Core

> Aplicação web e API em ASP.NET Core, organizada em camadas de domínio, infraestrutura e serviços.

## Organização

- `Controllers/` — endpoints e controladores da aplicação.
- `Domain/` — modelos e regras de domínio.
- `Infrastructure/` — acesso a dados e integrações.
- `Properties/` — projeto ou módulo `Properties`.
- `ServiceApplication/` — serviços e integrações da aplicação.
- `Utils/` — projeto ou módulo `Utils`.
- `Views/` — interfaces e páginas da aplicação.
- `wwwroot/` — projeto ou módulo `wwwroot`.

## Tecnologias

C# e .NET; o projeto web utiliza ASP.NET Core.
